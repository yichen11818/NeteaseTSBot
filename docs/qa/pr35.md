# PR #35 验收记录

核验日期：2026-11-19。范围：本地源码、隔离浏览器和 PR CI；未修改生产、灾备或真实网易云账号。

## 回归覆盖

- 后端校验完整收藏的分批详情、时间戳、原始顺序、外部 API 分页和空收藏；HTTP、业务码、非 JSON 及无效时间戳失败显式返回错误，不产生假完整结果。
- 前端覆盖旧版 200 首分页缓存升级、完整缓存复用、强制刷新、不完整响应拒绝、退出账号及刷新后显示数量重置。
- 搜索覆盖歌名、歌手与专辑，排序先于显示截取，触底阈值保留 120px。

## 浏览器功能与视觉验证

使用本机 Chrome 的隔离会话，接口数据由测试路由提供：450 首歌曲、20 台服务器；所有名称、Cookie 和点歌请求均为测试数据。没有连接真实 TeamSpeak 或调用真实网易云服务。

| 场景 | 检查结果 |
| --- | --- |
| 旧缓存升级 | 旧首屏缓存被替换，初始显示 200 首 |
| 自动追加 | 滚动后依次显示 400、450 首 |
| 完整搜索 | 可查到第 450 首的歌手、第 449 首的专辑；无匹配时显示明确空结果 |
| 排序与刷新 | 添加时间倒序、名称顺序和原顺序均正确；刷新重置为 200 首 |
| 请求失败 | 刷新时注入收藏时间 HTTP 500，页面显示明确错误 |
| 歌曲操作 | 加入队列、立即播放的测试请求正确；本地收藏可添加后取消 |
| 服务器浮层 | 20 项可滚动；方向键、End、Enter、Escape、外部点击及焦点返回已检查 |
| 服务器隔离 | 切换到第二台服务器并进入喜欢页，显示未配置 Cookie，不继承第一台凭证 |
| 响应式与主题 | 1440px、390px、320px；浅色/夜间模式，未见新控件横向溢出或歌曲操作按钮被裁切 |

验收同时修正了窄屏操作列与刷新按钮可访问名称，以及 Vue scoped 样式中 `:global()` 的完整选择器范围。浏览器会话和临时开发服务均已关闭。
